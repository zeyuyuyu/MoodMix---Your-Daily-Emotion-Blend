# MoodMix
A viral web app that lets users create and share their daily emotional state through an interactive color mixing experience. Users blend colors representing different emotions, creating a unique 'mood palette' that can be shared, tracked over time, and compared with friends.

Key Features:
- Interactive color mixing interface
- Daily mood tracking with beautiful visualizations
- Social sharing capabilities
- Weekly/monthly mood patterns
- Engaging animations

Tech Stack:
- HTML5 Canvas for color mixing
- Vanilla JavaScript for interactivity
- CSS animations
- LocalStorage for tracking
